# Dev Process

## DO's

- Write component
- Write unit tests
- UI should be generic components
- types and interfaces for features, hooks, constants, apis should extract to `./types`
- responsive design for optimial cross platform. 


## DO NOT

- Execute unit tests.

## Component structure

- named exports
- use className
- function signature `const someFn = ({}:<>) => {}; export { someFn };`
